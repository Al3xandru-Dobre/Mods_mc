# Minecraft cu fetite Anime + BMC(Better Minecraft 6)

## 1. Introducere

In acest modpack, am combinat Better Minecraft 6 + alte mod-uri. Acesta este un scurt tutorial pentru a va
seta jocul si a va putea conecta si juca impreuna cu noi.

## 2. Requirements
- Java 21 / Java 25 (il gasesti pe link-ul asta sa-l instalezi) : https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html  ![alt text](image.png) 
- Minecraft 26.1.2 (NeoForge)
- Better Minecraft 6 (v7): https://www.curseforge.com/minecraft/modpacks/better-mc-bmc6/files/9167833
- Modpack-ul lui Alexis:  https://drive.sopy.one/s/ELmyKK5JW5bfSk8
- Unul din serverele noastre de discord: Vladivostok: https://discord.gg/FfAK4hdbKg ; Sanatate Mentala Romania: https://discord.gg/SgZkGyJJ8M

## 5. Mini tutorial pentru instalare.

Prima data, este recomandat pentru convenienta, sa instalezi Better Minecraft 6 (BMC6).

Pentru comoditate, recomand sa apesi pe _Install via app_, iar o instanta de CurseForge va incepe.
Nu instala Overwolf.

![alt text](image-1.png)

Dupa acest pas, ruleaza jocul o data. Apoi, din meniul principal al jocului apasa pe butonul de mods:
![alt text](image-2.png)

Apasa apoi pe open mods directory. 

![alt text](image-3.png)

Acolo doar vei copia, din arhiva modpack-ului lui Alexis, toate fisierele jar. (Pro tip: Inchide jocul in timp de copieze.)

Enjoy.
